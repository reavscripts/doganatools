# Fonti doganali

Questa cartella è predisposta per documentare provenienza, licenza, versione e
modalità di recupero dei dataset ufficiali importati.

Il file in `processed/customs-dataset.json` incluso nell'MVP contiene soltanto
`TEST DATA` e non rappresenta TARIC, Nomenclatura Combinata o altre fonti ufficiali.

Prima dell'uso operativo occorre importare e validare almeno:

- nomenclatura TARIC/CN valida alla data di classificazione;
- gerarchia e descrizioni multilingua;
- note di sezione, capitolo, voce e sottovoce;
- regolamenti di classificazione e, se disponibili, precedenti CLASS/ITV;
- misure TARIC con ambito geografico e periodo di validità.
